POUR LES INGÉNIEURS

Comment c’est construit

Touchez pour déplier.

Modèles

Un modèle plus léger traite les 15 lectures de capteurs. La conversation — au poste et sur Telegram — tourne sur un modèle plus capable.

Matériel et hébergement

ATHENA vit sur une appliance dédiée — un portable reconverti en serveur Ubuntu Server sans écran — séparée du PC. C’est ce qui lui permet de rester joignable et de rallumer le PC.

Chaîne audio

La fenêtre de décision du mot d’activation est lue dans le modèle au chargement, jamais codée en dur. Porte anti-larsen : seul le détecteur est coupé, pas le flux audio ; elle se ferme avant le premier son, se réinitialise à la réouverture, garde une marge de sécurité, et se rouvre même si la synthèse vocale plante.

Interface

Tableau de bord web avec orbe en shader WebGL, tuiles en direct pour chaque capteur, vues caméra et graphiques intégrées. La même interface tourne sur ordinateur et sur téléphone.

Sécurité

Pare-feu limité à une seule machine cliente, SSH par clé uniquement, mises à jour automatiques. API authentifiée par jeton. Les écritures (mail, documents) demandent toujours une confirmation manuelle, jamais la seule voix.

Méthode de développement

Conception produit, architecture et intégrations sont les miennes. L’implémentation se fait en pilotant des agents de code IA, avec vérification systématique avant chaque mise en service.
